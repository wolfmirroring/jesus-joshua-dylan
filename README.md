# El Rincón del Grano ☕

Landing page ficticia para un negocio de café de especialidad, creada como proyecto grupal.

## Descripción del proyecto

**El Rincón del Grano** es una página web sencilla que presenta un negocio de café de origen, pensada para mostrar sus productos, servicios y forma de contacto de manera clara y atractiva.

## Secciones de la página

- **Inicio**: presentación del negocio y su eslogan.
- **Servicios**: los 3 productos/servicios principales que ofrece (café de especialidad, barra de preparación y grano para llevar).
- **Contacto**: información de contacto ficticia (dirección, teléfono, horario y redes sociales).
